# Task 1 — ML Classification

## Objective
Build a machine-learning classification system and compare two algorithms.

## Dataset
This project uses the built-in Breast Cancer Wisconsin dataset from `scikit-learn`, so no external dataset download is required.

## Algorithms
1. Logistic Regression
2. Random Forest Classifier

## Evaluation
The notebook evaluates:
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix
- ROC curve

## Run
```bash
pip install -r requirements.txt
jupyter notebook
```

Open:
`notebooks/customer_classification.ipynb`

## Output
The notebook saves the trained model and evaluation plots in `models/` and `plots/`.
